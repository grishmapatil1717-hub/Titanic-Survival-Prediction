# Titanic Survival Prediction

## Project Overview
This is a Machine Learning project that predicts whether a Titanic passenger survived or not using a Decision Tree Classifier.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Dataset
Titanic dataset containing passenger information.

Selected Features:
- Pclass
- Sex
- Age
- Fare

Target:
- Survived

## Data Cleaning
- Removed missing values.
- Converted gender into numerical values.
- Selected important columns.

## Machine Learning Algorithm
Decision Tree Classifier

## Model Results
- Baseline Accuracy: 59.4%
- Model Accuracy: 79.7%

## Visualizations
- Confusion Matrix
- Decision Tree Overfitting Analysis
- Feature Importance Graph

## Conclusion
The model achieved 79.7% accuracy and performed better than the baseline. This project helped me understand data cleaning, model training, testing and evaluation.
